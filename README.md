# STICKMAN — Shadow World

An original 3D open-world mobile adventure project made with Godot 4.

## Current playable foundation
- Procedurally generated city blocks, roads, a central plaza and a landmark tower.
- Dynamic day/night lighting and world clock.
- Custom low-poly Stickman character assembled from 3D meshes.
- Third-person and first-person camera toggle.
- Walking, sprinting, stamina and jumping.
- Touchscreen movement/action controls and desktop keyboard controls.
- Mobile-friendly Godot GL Compatibility renderer.

## Controls
- Move: WASD / arrow keys
- Sprint: Shift
- Jump: Space
- Switch camera: V
- Look: mouse or drag on the right side of the screen
- Android: on-screen controls

## Build target
- Engine: Godot 4.4.1
- Android: debug APK first, then a signed release build after export setup.
- The Android APK is not yet generated by this repository revision.

## Roadmap
1. Character controller, camera, touch controls and city blockout.
2. Parkour traversal, climbing, ledges and interaction system.
3. Enterable interiors, shops, NPC routines and dialogue.
4. Jobs, currency, property ownership, inventory and save slots.
5. Story missions, side quests, puzzles, vehicles and world events.
6. Weather, art/animation pass, audio, device profiling and Android packaging.

This is an evolving game project. The current build is a prototype foundation, not yet the complete open-world experience described in the design brief. Large-scale production quality requires original art, animation, audio, testing and optimization over multiple development milestones.
