# STICKMAN: SHADOW WORLD

An original 3D mobile open-world adventure project built with Godot 4.4.1.

## Current prototype systems
- Procedurally generated city blocks, roads, windows, a central plaza and an old clock tower.
- Town trees, street lamps and a furnished starter townhouse interior.
- Working entrance and exit portals between the city and the townhouse.
- Dynamic directional sunlight and a running world clock.
- Procedural moving 3D cloud formations with layered silhouettes and slow atmospheric drift.
- Filmic tone mapping, subtle glow and distance fog, with mobile-friendly quality scaling.
- Four graphics presets: performance, balanced, high visual and cinematic maximum.
- Custom 3D Stickman assembled from meshes, with a basic procedural walk cycle.
- First-person / third-person camera switching with free vertical and horizontal look.
- Configurable look sensitivity, field of view, third-person camera distance and inverted vertical look.
- Pause menu, settings panel, graphics quality presets, FPS caps and persistent local settings.
- Resizable touch controls with left-hand/right-hand layout selection.
- Walking, sprinting, stamina, jumping, contextual wall jumps and obstacle vaults.
- Touchscreen controls, right-side touch camera look, and desktop keyboard controls.
- HUD with coins, XP, stamina, interaction prompts and world time.
- Starter economy, inventory data, mission state and property ownership data.
- Interactable mission board, job office, supply shop and purchasable townhouse.
- Six wandering residents with dialogue and basic movement AI.
- Local save/load system using the device's user data directory.

## Controls
- Move: WASD / arrow keys
- Sprint: Shift
- Jump: Space; press jump again in the air near an obstacle for a parkour move
- Switch camera: V
- Pause / settings: Escape or the on-screen MENU button
- Interact: E
- Save: F5
- Load: F9
- Look: mouse or drag on the right side of the screen
- Android: on-screen controls

## Android target
The project uses Godot's mobile GL Compatibility renderer. Android export configuration, device testing and APK packaging are still pending. No APK is produced by the current validation workflow.
