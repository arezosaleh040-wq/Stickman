# STICKMAN: SHADOW WORLD

An original 3D mobile open-world adventure project built with Godot 4.4.1.

## Implemented prototype systems
- Procedurally generated city blocks, roads, windows, central plaza and an old clock tower.
- Dynamic directional sunlight and a running world clock.
- Custom 3D Stickman assembled from primitive meshes, with a basic procedural walk cycle.
- First-person / third-person camera switching.
- Walking, sprinting, stamina and jumping.
- Touchscreen controls, right-side touch camera look, and desktop keyboard controls.
- HUD with coins, XP, stamina, interaction prompts and world time.
- Starter economy, inventory data, mission state and property ownership data.
- Interactable mission board, job office, supply shop and purchasable townhouse.
- Local save/load system using the device's user data directory.

## Controls
- Move: WASD / arrow keys
- Sprint: Shift
- Jump: Space
- Switch camera: V
- Interact: E
- Save: F5
- Load: F9
- Look: mouse or drag on the right side of the screen
- Android: on-screen controls

## Android target
The project is designed around Godot's mobile GL Compatibility renderer. Android export configuration, device testing and APK packaging are still pending. No APK is produced by the current validation workflow.
