# STICKMAN

An original 3D mobile adventure project built with Godot 4.

## Current milestone
- 3D third-person character controller
- First-person / third-person camera toggle
- Procedurally generated prototype town
- Keyboard controls for desktop testing
- On-screen touch controls for Android testing

## Controls
- Move: WASD / arrow keys
- Jump: Space
- Toggle first/third person: V
- Mobile: use the on-screen controls

## Engine
Godot 4.4.1

## Android
Android export configuration and APK automation will be added after the starter project is validated in Godot. A debug APK is the first Android target; release signing will require a user-owned keystore.

This is an early playable foundation, not the complete open-world game. Large world systems, interiors, missions, NPCs, economy, vehicles, weather, and save slots will be developed in milestones.
